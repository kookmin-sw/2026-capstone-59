# assets/

GitHub Pages 소개 페이지(`index.md`)와 `README.md`에서 사용하는 이미지·에셋 파일 저장 폴더.

## 현재 파일 목록

| 파일명 | 용도 | 상태 |
|---|---|---|
| `logo.png` | Poco 로고 (README·index.md 상단) | ✅ |
| `architecture.png` | 시스템 아키텍처 다이어그램 (index.md §4-1) | ✅ |
| `poster.png` | 완성된 포스터 이미지 (index.md 최상단) | 🔴 외주 완성 후 |

## 파일 업로드 방법

1. 이 폴더(`assets/`)에 **영문 파일명**으로 이미지 업로드
   - 한글 파일명·공백은 URL 인코딩 문제로 깨질 수 있어 피해주세요
2. 업로드 후 `index.md`의 해당 `<!-- TODO -->` 주석 해제
3. `master` 브랜치에 push 시 GitHub Pages가 자동 반영 (1~2분 소요)

## 권장 사양

- **형식:** PNG (배경 투명 권장) 또는 JPG
- **해상도:** 가로 1200px 이상 권장 (Retina 대응)
- **파일 크기:** 1MB 이하 권장 (페이지 로딩 속도)
